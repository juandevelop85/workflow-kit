# T1.3 · Split the checker into modules

> **Status:** ⏳ Pending
> **Phase:** Phase 1 (credibility)
> **Priority:** Medium
> **Date:** 2026-11-01
> **Depends on:** T1.2
> **Origin:** audit (the checker does seven jobs in one file of 608 lines, close to the 800-line warning it imposes on others)

## Description

`workflow_check.py` mixes configuration, globs, presets, checks, git and the subcommands. The next
features (T1.4, T1.5) would push it past the kit's own warning size.

## Technical Scope

1. Move the code into a `workflow_kit/` package next to the script (`config`, `globs`, `gitutil`,
   `checks`, `review`, `gates`, `cli`); `workflow_check.py` stays the entry point.
2. Pure move: no behaviour change, the same tests before and after.
3. Out of scope: any fix (T1.4).

## Acceptance Criteria

- Every test that passed before passes unchanged. test: the whole suite (`python3 -m unittest discover -s tests`)
- No module of the checker exceeds 400 lines. test: test_no_checker_module_is_large
- The installer copies the package and the installed checker runs. test: test_installed_checker_runs_from_the_package

## Risks

An import that works from the kit but not once installed: covered by the installed-checker test.
