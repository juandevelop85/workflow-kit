## Description

code found statements that were no longer true (principle 5: documentation describes current
behaviour).

1. `docs/method.md`: traceability of quick changes; the procedure layer classifies; which reviewers

   pieces table (`review-plan --write-diff`, `fingerprint`).

   matched the list; `--root`, `--help`, the review hand-off files, the cache's symlink refusal.
3. `docs/adoption.md`: start with `/change`; the new protections and the known limit (T1.7).
4. `core/commands/ticket-run.md` and `ticket-review.md`: reviewers come from `review-plan`;
   fingerprint around `test-auditor`.
5. `CHANGELOG.md`: 4 skills and 7 commands; lane signals; the known limit.
6. `.agents/rules/project.md`: where the security regression tests live.
7. `core/skills/ticket-author/SKILL.md` (found in review): the security reviewer is chosen by the
   sensitive globs, not by the ticket's Risks text.
8. `tests/test_kit_hygiene.py`: documented subcommands equal the CLI's; command references are
   checked in `.md` and `.tmpl` under `core/`, in `docs/`, the README, the changelog and AGENTS.md;
   agent and skill names must appear as whole words outside their own file.
9. Out of scope: behaviour changes.
