# T1.4 · Honest closing and a stricter backlog

> **Status:** ⏳ Pending
> **Phase:** Phase 1 (credibility)
> **Priority:** High
> **Date:** 2026-11-01
> **Depends on:** T1.3
> **Origin:** audit

## Description

"Honest closing" only checked that the words "Acceptance Criteria" appeared somewhere in a done
ticket. Statuses typed without the emoji variation selector were not recognised; duplicate ids and
links to the wrong directory passed; the default commit pattern ignored `[tickets].id_pattern`; a
malformed baseline line crashed with a traceback. A commit could cite a ticket that does not exist
(the kit's own history cites T43.1, a ticket of another project).

## Technical Scope

1. A done ticket needs an `Acceptance Criteria` *section* with at least `done_min_criteria`
   (default 1) items.
2. Statuses compared after removing U+FE0F.
3. Duplicate ids in the backlog are an error; a row's link must resolve to the ticket file.
4. One backlog-row parser, used by `check` and `context`.
5. Without `[commits].pattern`, the default is built from `[tickets].id_pattern`.
6. A malformed baseline line is a configuration error with its line number.
7. A commit's ticket id must exist in the backlog; history from before the adoption is exempted
   explicitly with `[commits].since = "<ref>"` (only `<ref>..HEAD` is checked).
8. Outside a git repository the commit check is a clear error, not a traceback.

## Acceptance Criteria

- An empty criteria section, or the words in prose, do not close a ticket. test: test_done_needs_a_real_criteria_section
- `⏸` and `⏸️` are the same status. test: test_status_without_variation_selector_matches
- Duplicate ids are reported. test: test_duplicate_ids_are_an_error
- A link to another directory is reported. test: test_link_must_point_at_the_ticket_file
- A custom id pattern drives the default commit pattern. test: test_default_commit_pattern_follows_id_pattern
- A malformed baseline is a clear error. test: test_malformed_baseline_is_a_config_error
- A commit citing a ticket that is not in the backlog is reported. test: test_commit_must_cite_a_ticket_of_the_backlog
- `[commits].since` limits the check to later commits. test: test_commits_since_exempts_older_history
- No git repository: a clear error. test: test_commit_check_outside_git_is_an_error

## Risks

Stricter checks may fail existing backlogs: each error says what to fix.
