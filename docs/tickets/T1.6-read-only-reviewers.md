# T1.6 · Review agents that really are read-only

> **Status:** ⏳ Pending
> **Phase:** Phase 1 (credibility)
> **Priority:** Medium
> **Date:** 2026-11-01
> **Depends on:** T1.5
> **Origin:** audit ("read-only" was a request in the prompt, not a permission: the agents had Bash)

## Description

The review agents declared themselves read-only but had `Bash`, which can edit, commit or push.

## Technical Scope

1. Remove `Bash` from the three review agents; `review-plan --write-diff` writes the diff to
   `.agents/.cache/review/diff.patch` for them to read; the gates already ran the tests.
2. The hygiene test forbids `Bash`, `Edit`, `Write` and `NotebookEdit` in review agents.

## Acceptance Criteria

- No review agent has a tool that can change files. test: test_every_skill_agent_and_command_has_valid_frontmatter
- `review-plan --write-diff` writes the full diff, untracked files included. test: test_review_plan_writes_the_diff_for_reviewers

## Risks

Requires security review. Reviewers can no longer run a check to confirm a finding; they rely on the
gate logs, which they can read.
